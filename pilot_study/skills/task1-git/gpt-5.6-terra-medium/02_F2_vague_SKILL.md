# Generate an Open Issue Report

1. Use the `gh` CLI to retrieve every open issue from repository X, excluding pull requests, and arrange the results from most recently updated to least recently updated.

2. Create `issue_report.md` and state the total number of retrieved issues.

3. List each issue by its number and title.

4. Mark the three most recently updated issues with a star.

5. Save the report as `issue_report.md`.
